# CANNON MULTIPLIER（仮タイトル）

大砲で兵士を撃ち出し、**城門で倍増**させて、押し寄せる敵を食い止める、PC向けのアクションゲームです。
軍資金をやりくりして設備（柵・大砲・火責め）を置き、ステージクリアのたびに設備を強化していきます。

## ダウンロードと起動（Windows）

1. このページの右側にある **「Releases」** から、最新の `cannon-multiplier-vX.X.X-win-x64.zip` をダウンロードします
2. zip を**解凍**します（解凍したフォルダごと使います。exe だけを取り出さないでください）
3. 中の `cannon-multiplier.exe` を起動します
   - 初回だけ、Windows の「PC が保護されました」という画面が出ることがあります。**「詳細情報」→「実行」** を選んでください（個人で作ったゲームのため、署名がないことが原因です）
4. 音が出ます。ボリュームは、ゲーム内の「オプション」で調整できます

インストールは不要です。遊ばなくなったら、解凍したフォルダを削除すれば消えます。

## 操作

| 操作 | 内容 |
|---|---|
| `A` `D` / `←` `→` | 大砲を左右に動かす（兵士は自動で発射） |
| 画面左の「設備メニュー」を左クリック（または `1` `2` `3`） | 設置する設備を選ぶ |
| 橋の上を**右クリック** | 選んだ設備を設置する（門より奥に置けます） |
| `Esc` | メニュー（ゲームに戻る / オプション / タイトルに戻る） |
| `F11` | 全画面の切り替え |

## ルール

- 兵士は**城門**を通ると、表示された倍率ぶん増えます。増えた兵士が、奥から迫る敵と戦います
- 敵は**城門を攻撃**します。門に着かれるたびに、城門 HP が減ります。0 になると負けです
- 敵を倒すと**金貨**が落ちます。**大砲を動かして受け止める**と、軍資金が増えます
- 奥から流れてくる**📦 支援物資のコンテナ**は、壊すとアイテムが出ます（攻撃・連射・門の強化）。**大砲で受け止めて**取りましょう。壊し損ねると、海に投げ落とされます
- 設備（軍資金を使います）
  - 🪵 **柵**：敵は壊すまで先へ進めません（兵士は通れます）
  - 💣 **大砲**：着弾地点が爆発して、周囲にダメージ
  - 🔥 **火責め**：一定時間、周囲の敵に持続ダメージと足止め
- ステージをクリアすると、**設備強化を3つの中から1つ**選べます
- 最初の1分は、軍資金を貯める時間です。そのあとは、設備を使いこなせるかが勝負です
